## What each folder contains

Each case study folder includes:

- `README.md` — problem statement, objectives, assumptions, algorithm, pseudocode, test cases, output and conclusion
- `flowchart.png` — flowchart of the program
- `solution.py` — Python source code
- `test_cases.py` — test cases for checking the program
- `output.txt` — program output
- `output_screenshot.png` — screenshot of output
- `demo_input.txt` — sample input (only for menu-driven programs: case 7 and case 10)
